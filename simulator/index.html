Dostępne API (styl Arduino) — kliknij, aby rozwinąć

Struktura: zdefiniuj function setup() i function loop(), dokładnie jak w szkicu Arduino. Pauzy rób przez await delay(ms) — dlatego loop może być async (zobacz przykłady).

GPIO: pinMode(pin, OUTPUT|INPUT|INPUT_PULLUP) · digitalWrite(pin, HIGH|LOW) · digitalRead(pin) · analogRead(pin) (0–4095) · neopixelWrite(48, r, g, b)

Czas: await delay(ms) · millis() · micros()

Serial: Serial.println(x) · Serial.print(x) · Serial.printf("%d", x)

OLED (Adafruit_GFX): display.clearDisplay() · display.setCursor(x,y) · display.setTextSize(n) · display.print(txt) / println(txt) · display.drawPixel(x,y,c) · drawLine · drawRect · fillRect · drawCircle · fillCircle · display.display() (odśwież)

Piny: LED=GPIO2, RGB=GPIO48, BOOT=GPIO0, przycisk=GPIO14 (oba z pull-up → wciśnięty = LOW), potencjometr=GPIO4.

Symulator działa w przeglądarce — logika JavaScript w stylu Arduino. Nie zastępuje realnego sprzętu w 100%, ale pozwala szybko sprawdzić UI i logikę softu.
